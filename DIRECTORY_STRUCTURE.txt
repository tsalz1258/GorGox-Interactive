QUICK START PATHS
=================
1. First Time Setup:
   → install_rust.bat                       Install Rust
   → cargo build --release                   Build project
   
2. Run Server:
   → start.bat                              Launch server
   OR
   → cargo run --release                     Build & run
   
3. Access Interface:
   → Open: http://localhost:3000
   
4. Load Sample Data:
   → python populate_sample_data.py

RUST BACKEND (src/)
-------------------
main.rs                Initializes database, game state, and server
server.rs              Handles WebSocket connections, HTTP routes, messages
models.rs              Defines Character, Enemy, Token, Combat, Messages
db.rs                  SQLite operations (save/load characters, enemies, maps)
combat.rs              Initiative tracking, turn management, damage/healing
game_state.rs          Tracks players, tokens, combat state in memory

WORKFLOW DIAGRAM
================

1. START HERE
   ↓
   install_rust.bat (first time only)
   ↓
   start.bat
   ↓
   Server runs on http://localhost:3000
   ↓

   ↓
   
2. PREPARE GAME
   ↓

   ↓
   Add characters (examples/sample_characters.json)
   ↓

   ↓
   Place tokens on map
   ↓
   Start combat
   ↓
   Initiative rolls automatically
   ↓
   Manage turns, damage, healing
   ↓
   End combat
