========================================
  URGENT: FIX BUILD ISSUE
========================================

Windows Defender is blocking the Rust build.

YOU MUST ADD AN EXCLUSION TO FIX THIS.

========================================
  METHOD 1: Windows Security (EASIEST)
========================================

1. Press Windows Key + I
2. Click: Privacy & Security
3. Click: Windows Security  
4. Click: Virus & threat protection
5. Click: Manage settings (under "Virus & threat protection settings")
6. Scroll down to: Exclusions
7. Click: Add or remove exclusions
8. Click: + Add an exclusion
9. Click: Folder
10. Navigate to and select:
    C:\Users\tyler\OneDrive\Desktop\DND\gorgox-interactive-github\GorGox-Interactive

11. Click: Select Folder

THEN RUN:
    cargo clean
    cargo build --release

========================================
  METHOD 2: PowerShell (as Administrator)
========================================

1. Right-click PowerShell → Run as Administrator
2. Run this command:
   
   Add-MpPreference -ExclusionPath "C:\Users\tyler\OneDrive\Desktop\DND\gorgox-interactive-github\GorGox-Interactive"

3. Then run:
   cargo clean
   cargo build --release

========================================
  TEMPORARY WORKAROUND
========================================

If you have an existing build, you can use it:

Check if you have:
- target\release\gorgox_interactive.exe
- target\debug\gorgox_interactive.exe

If yes, you can run it directly without rebuilding!

========================================
  WHY THIS IS HAPPENING
========================================

Windows Defender is flagging Rust-compiled executables as suspicious.
This is a FALSE POSITIVE - Rust builds are completely safe.
Adding the exclusion tells Windows Defender to ignore this folder.
