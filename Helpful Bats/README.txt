================================================================================
                         HELPFUL BATCH FILES
================================================================================

These are helper scripts for setup and troubleshooting.
You probably won't need these during normal use.

--------------------------------------------------------------------------------
INSTALLATION & SETUP
--------------------------------------------------------------------------------

install_rust.bat              - Install Rust programming language
install_msvc_tools.bat        - Install Visual Studio Build Tools
setup_everything.bat          - Complete setup wizard

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

fix_antivirus.bat             - Add antivirus exclusion for project
fix_database.bat              - Fix database permission issues
allow_firewall.bat            - Add Windows Firewall rule for port 3000

--------------------------------------------------------------------------------
NETWORKING
--------------------------------------------------------------------------------

get_my_ip.bat                 - Show your IP address for players
start_with_ngrok.bat          - Start server with ngrok tunnel (internet)

--------------------------------------------------------------------------------
DATA
--------------------------------------------------------------------------------

load_sample_data.bat          - Load sample characters and enemies
QUICK_FIX_RESTART.bat         - Quick restart with fixes

--------------------------------------------------------------------------------

MAIN FILES (in root folder):
  - start.bat                 - Start the server (USE THIS!)
  - build.bat                 - Build the project
  - run.bat                   - Just run the server
  - FINAL_RESTART.bat         - Restart with all improvements
  - RESTART_WITH_FIXES.bat    - Apply fixes and restart

Most of the time, you just need: start.bat

================================================================================
