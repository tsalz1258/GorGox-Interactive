# SW5E rules used by the first automated power set

Verified on the official SW5E website October 2, 2026 using its rendered rules pages (the site requires JavaScript).

- Casting cost: level 0 costs zero; levels 1–9 cost casting level plus one. Higher-level casting uses that higher level's cost. [Casting](https://sw5e.com/rules/phb/casting)
- Engineer tech points: twice Engineer level plus Intelligence modifier. Tech attack adds proficiency and Intelligence; save DC adds 8. Engineers can use each casting level 6–9 once per long rest. [Engineer](https://sw5e.com/characters/classes/Engineer)
- Electroshock: touch, melee tech attack, 1d8 lightning, increases at character levels 5/11/17; advantage against metal; Shocked until the target's next turn. Critical attacks double damage dice. [Tech powers](https://sw5e.com/rules/phb/casting/techPowers)
- Explosion: level 3, range 150 feet, radius 20 feet, DEX save, 8d6 fire with half damage on success; adds 1d6 per higher casting level. [Tech powers](https://sw5e.com/rules/phb/casting/techPowers)
- Kolto Pack: level 1, range 60 feet, bonus action, heals 1d4 plus casting ability; adds 1d4 per higher casting level; cannot heal droids/constructs. [Tech powers](https://sw5e.com/rules/phb/casting/techPowers)

Scope: the DM reviews cover, saving-throw bonuses, resistances, immunity, advantage, and action economy. The server checks caster ownership, casting level, points, supported range/area, unchanged preview targets, and duplicate commitment. Default save bonuses include PC ability/proficiency where available; enemy bonuses require DM review. Unsupported powers use explicit manual effects with the correct point cost. Concentration saves require DM confirmation; duration can be tracked in rounds or ended manually. Force point maxima for unsupported classes require imported sheet values or a DM override; they are not guessed from total character level. External rule changes are not automatically imported.
