🔗 Link Discord Account

Link your Discord account to this character so your token highlights when you speak in Discord voice channels.

How to get your Discord User ID:

  1. Open Discord (desktop or web)
  2. Go to User Settings (gear icon ⚙️)
  3. Go to "Advanced" section
  4. Enable "Developer Mode"
  5. Right-click on your own username/avatar
  6. Click "Copy User ID"

Your User ID is a long number like: 123456789012345678
